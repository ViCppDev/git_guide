# git commands guide

## what is git?
git is a command-line tool that helps you work with the code repositories and add them to online services (like GitHub, GitLab, etc.)
git also helps you to track all your project versions and work with other developers without a need to rewrite all the code at slight changes of your colleagues

## who is this guide for?
this guide will help you learn how to use git in your projects

## structure
this file (README.md) is a file where I'd described everything to help you navigate in project

commands.md - a file with git commands to use 

terms\_explanation.md - a file with explanation of some terms

screenshots - a directory (a directory is similiar to a folder in Windows) with some screenshots about git working
